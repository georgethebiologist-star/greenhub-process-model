## First parameter-level evidence check: press yield

Label correction: the sentence below describes the 2026-11-10 pre-normalization
snapshot. The current canonical registry and normalized FAIR input both mark
the default E; the distinct PRESS-001 literature candidate remains B-tier for
its timothy-grass observation only.

The active F1 workbook setting `phase3.juice_yield_kg_per_kg_wet_feed` is a 0.5 kg/kg wet structural consistency target, and the canonical parameter registry and current normalized FAIR input both mark it E with no DOI. An earlier export's D label is retired; the numeric target and override precedence were not changed. The activation registry also contains a separate active D4 timothy-literature candidate (`PRESS-001`) whose methods include added water. That candidate must not be conflated with the workbook target or treated as roadside calibration.

The existing Grassification D2.3.1 extract is a closer **reference**: a Utrecht roadside-grass press session reports 42.8% liquid mass of fresh feed and 57.4% fibre (100.2% total), while a Maldegem session reports approximately 40/60%. Both used a Rhinetech back-pressure screw press. These source figures have a compatible *reported* wet-feed denominator for a provisional 0.428/approximately 0.40 kg/kg comparison, but only two sessions, different cuts/sites and uncertain closure; GreenHub's press settings and any added-water/return-liquid boundary have not been shown to match. They therefore do **not** replace 0.5 or prove a transferable regression. Next data request: the GreenHub/VARTA same-batch weighed feed, added water, juice and cake, paired DM/protein assays, date, hold time and press settings, including whether any liquid is recycled. Preserve the existing fallback and user override until those checks pass.

Collection rule: obtain a linked campaign across all stages using a persistent sample/batch ID, cut date and site, receiving mass, a shared wet/dry basis, timestamps, equipment configuration and route, every inlet/outlet stream, measurement method, uncertainty, usage rights and source location. Classify observations as GreenHub measured (A), direct literature observations (B), literature-informed project assumptions (C), or unverified/unsupported placeholders (E); D remains a legacy read-only code and must not be assigned to new records. Keep explicit missingness separate from measured zero. Promote a literature row only after feedstock, technology, boundary, denominator, time/scale, uncertainty and equation mapping pass; otherwise retain it as a reference comparator and preserve the flagged fallback. No defaults, registry values, workbook cells, routes, UI overrides or Pareto results are changed by this queue.

## Project-measured material already on hand

The archived 27 October 2026 VARTA workbook has English machine-readable fibre/whole-grass and juice extracts. The `Greenhub whole grass` fibre row (source row 7, sample 3) is dated 16 July 2026 and reports 14.3% dry matter plus nutrient concentrations. The `Greenhub (grass sample)` juice row (source row 5, sample 1) has nutrient concentrations but **no sample date** in the extract. The extracts do not carry a common batch ID, press inlet/outlet masses, or a documented link proving that these two rows are paired. The existing `grass_varta_default` feed profile can use the measured whole-grass assays, but it must not infer a Phase 3 component partition or press yield by dividing the two analyses. Ask VARTA for original sample lineage, sampling dates, press logs and matched masses before doing that. Lab report values are project measurements for their own samples; they are not a seasonal mean.
