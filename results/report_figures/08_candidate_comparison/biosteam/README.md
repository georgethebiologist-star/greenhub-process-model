# Superseded candidate exports

PNG, CSV and JSON files in this folder come from earlier Pareto runs. They do not correspond to the latest no-PEF, RVO-labelled paired analysis and their old rank numbers are not comparable. Use the `protein_enabled/` and `protein_bypass/` candidate folders at this directory level, `Greenhub/results/pareto_rvo_2026/`, and `results/report_figures/rvo_pareto_figure_index.csv` for current results.
