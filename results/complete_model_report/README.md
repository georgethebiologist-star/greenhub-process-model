# Historical GreenHub report package

This copied PDF, HTML, markdown report, atlas, candidate ledger, figures and evidence directory are a historical snapshot from an earlier optimization and CAPEX basis. Their candidate ranks and numerical conclusions are **superseded** by the current no-PEF RVO-labelled BioSTEAM Pareto launch. Do not cite this package as current.

The current report package is in [`../complete_model_report_rvo_2026/`](../complete_model_report_rvo_2026/). Current data are under `Greenhub/results/pareto_rvo_2026/`; current PNGs and their index are under `results/report_figures/`. Use the [Pareto methodology](../../docs/RVO_PARETO_METHODOLOGY.md), [current API documentation](../../docs/backend_pareto_jobs.md), and [current figure index](../report_figures/rvo_pareto_figure_index.csv).

This package remains in place for traceability because a previous cleanup attempt was rejected. Its contents have not been regenerated from the current run. The current website optimization and hotspot panels use the latest API artifact and stored run metadata, not this historical package.
